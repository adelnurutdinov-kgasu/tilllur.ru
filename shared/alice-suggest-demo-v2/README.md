Какие есть типы подсказок:

1. Статичная поисковая: "Найти" (currentQuery): Ваш запрос для обычного поиска.
2. Статичная Алисовая: "Алиса" (aliceQuery): Ваш запрос для Алисы.
3. Динамические поисковые текстовые подсказки
4. Динамические поисковые подсказки для ссылок

Длина запроса:
– Влияет на видимость элементов и активацию режимов.
– aliceAppPromo + aliceAppPromoThreshold: Если включено и запрос длиннее порога, "Алиса" отображается первой.
Инпутная кнопка:
– это кнопка, которая позволяет выполнить действие по текущей подсказке саджеста
– Клавиши ArrowDown и ArrowUp позволяют перемещаться между подсказками, включая currentQuery и aliceQuery.
– Клавиша Enter выполняет поиск/переход по активной подсказке.
– Клавиша Escape скрывает контейнер подсказок.
– Наведение мыши на подсказку также активирует ее.

Инпутная кнопка подстраивается под тип подсказки (поиск/переход по активной подсказке):
1. Статичная поисковая — "Найти в Яндексе"
2. Статичная Алисовая – "Спросить Алису"
3. Динамические поисковые текстовые подсказки – "Найти в Яндексе"
4. Динамические поисковые подсказки для ссылок — "Перейти"

Как перейти в Алису:

https://alice.yandex.ru/?alice_deeplink={"text":"Привет"} - откроет новый чат и отправит запрос

Получение подсказок (fetchSuggestions):

– Используется прокси https://api.allorigins.win/raw?url= для обхода CORS-политики при запросах к suggest.yandex.ru.
– Отмена предыдущих запросов (AbortController): Если пользователь быстро вводит текст, предыдущие незавершенные запросы отменяются, чтобы избежать устаревших результатов.
– Таймаут запроса (3 секунды).
– Парсинг JSONP-ответа от Яндекс.Саджеста.
