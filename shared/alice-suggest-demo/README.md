# Alice AI Suggest - Веб-прототип умного поиска

Этот проект представляет собой веб-реализацию механизма поиска, основанного на принципах из проекта browser-2025 для macOS.

## 🎯 Основные принципы

### 1. Умное определение типа ввода
- **URL-адреса**: Автоматически добавляется протокол `https://` для доменных имен
- **Поисковые запросы**: Отправляются в Яндекс для поиска
- **Валидация**: Проверка корректности URL перед обработкой

### 2. Подсказки в реальном времени
- Интеграция с API подсказок Яндекса
- Дебаунс запросов (300ms) для оптимизации
- Разделение на обычные подсказки и навигационные элементы

### 3. Интуитивная навигация
- **Стрелки ↑↓**: Навигация по подсказкам
- **Enter**: Выполнение поиска
- **Esc**: Закрытие подсказок
- **Клик**: Выбор подсказки мышью

### 4. Современный интерфейс
- Минималистичный дизайн
- Плавные анимации
- Адаптивная верстка
- Backdrop blur эффекты

## 🚀 Быстрый старт

1. Откройте `index.html` в браузере
2. Начните вводить текст в поле поиска
3. Используйте стрелки для навигации по подсказкам
4. Нажмите Enter для выполнения поиска

## 🔧 Технические особенности

### Логика asSuggestURL
```javascript
// Примеры преобразования:
"привет" → "https://ya.ru/search/?text=привет"
"mail.yandex.ru" → "https://mail.yandex.ru"
"https://google.com" → "https://google.com"
```

### API подсказок
- Используется прокси для обхода CORS
- Парсинг JSON ответа от Яндекса
- Обработка ошибок с fallback

### Производительность
- Дебаунс запросов подсказок
- Ленивая загрузка элементов
- Оптимизированные CSS анимации
